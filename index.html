Kelly (Zishan) Wang is a Canadian computer science student and software developer from the Don Valley North area of Toronto, Ontario. She is an incoming student in the Honours Bachelor of Computer Science Co-op program at the University of Waterloo, and is known for hackathon and science-fair projects including bing bang dream adventure, Sightread Showdown, and Codepull. She has held leadership roles including President of the AYJ Model United Nations Club and Deputy Premier in Ontario's Model Parliament Program, and has completed internships at organizations including St. Michael's Hospital and Waxis Inc.

Projects

bing bang dream adventure (2026)

A Bad Apple!! rhythm game synced to custom IMU-based flick controllers with six-direction input, inspired by Project Sekai and Beat Saber. A Python bridge service reads the controller's motion data over USB or WiFi and feeds flicks into the Godot-based game in real time. Source code.

Codepull (2026)

A web app that gamifies coding by turning time spent programming into gacha pulls, using the Hackatime API to convert every 10 minutes coded into a pull. Built with React and Vite. Source code.

Sightread Showdown (2025)

A sight-reading platform built at Jamhacks 9 that lets users compete by sight-reading pieces; the app converts audio input into a sequence of pitches and durations and uses the Gemini AI API to score accuracy. Source code · Dorahacks.

Home Optimization of Sterilization Economically (2024)

A regression-model-backed prototype, trained on data collected over six months of experimentation, aimed at making household item sterilization more accessible. Won a Gold Medal at the Toronto Science Fair. Source code · Devpost.

The Pencil Project (2023)

A prototype pencil designed to reduce environmental waste by 92% compared to a traditional pencil. Won a Bronze Medal at the Toronto Science Fair. View project.
